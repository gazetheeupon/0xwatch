# 0xwatch

Stay with the picture. Points mint while you watch. They unlock when advertisers actually pay.

Live: https://gazetheeupon.github.io/0xwatch/

Pictures are public-domain features and Blender open movies. No pirate feeds.

Points accrue at 1/min while this tab is visible and the film is playing (¼ rate if muted). They stay locked until ad receipts exist. The counter is not a payout.
